# Yaqona Connect 🌿

Yaqona Connect is a simple marketplace platform that connects yaqona farmers and buyers across Fiji.

## 🌱 Purpose
To make yaqona trading easier, faster, and more transparent by removing middlemen and connecting farmers directly with buyers.

## 🚀 Features (MVP)
- Farmers can post yaqona listings (quantity, price, location)
- Buyers can browse available yaqona
- Direct contact between buyer and seller (e.g. WhatsApp link)

## 🛠️ Built With
- HTML
- CSS
- JavaScript
- Firebase (Firestore Database)

## 📦 How to Run
1. Clone or download the project
2. Open `index.html` in a browser
3. Or use VS Code Live Server

## 🔥 Future Improvements
- User login system (farmers vs buyers)
- Real-time chat
- Mobile app version
- Payment integration
- Delivery tracking system

## 🌍 Vision
To modernize agricultural trade in Fiji starting with yaqona and empower local farmers with direct market access.
